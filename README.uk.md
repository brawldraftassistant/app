# Драфт-асистент — Brawl Stars Ranked (PWA)

Той самий застосунок, але тепер його можна встановити на телефон і користуватись офлайн.

## Що всередині

```
index.html              — сам застосунок (логіка не змінена)
manifest.webmanifest    — назва, іконки, колір, standalone-режим
sw.js                   — service worker: кешує все для офлайну
icons/                  — іконки 192/512, maskable, apple-touch, favicon
```

## Як запустити

PWA працює **тільки з https** (або з `localhost`). Просто відкрити `index.html`
подвійним кліком — не спрацює: service worker не зареєструється.

### Варіант 1 — GitHub Pages (безкоштовно, 5 хвилин)

1. Створи репозиторій на github.com, наприклад `draft-assistant`.
2. Залий туди всі файли з цієї папки (кнопка **Add file → Upload files**).
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через хвилину адреса буде `https://ТВІЙ_НІК.github.io/draft-assistant/`.

### Варіант 2 — Netlify Drop

Відкрий https://app.netlify.com/drop і перетягни туди папку. Посилання з'явиться одразу.

### Варіант 3 — локальна перевірка

```bash
cd папка_з_файлами
python3 -m http.server 8000
```

Далі відкрити `http://localhost:8000`.

## Як встановити на телефон

- **Android / Chrome** — знизу з'явиться панель «Встановити застосунок», або меню ⋮ → «Встановити застосунок».
- **iPhone / Safari** — кнопка «Поділитися» → «На екран «Додому»». (iOS не показує автоматичну панель — це обмеження Safari.)
- **Комп'ютер / Chrome, Edge** — іконка встановлення в адресному рядку.

Після встановлення застосунок відкривається без панелі браузера і працює без інтернету.
Угорі з'явиться жовта позначка «Офлайн — працює», коли мережі немає.

## Коли оновиш логіку

Зміни `index.html`, а тоді підніми версію в `sw.js`:

```js
const VERSION = 'draft-v2';   // було draft-v1
```

Без цього браузер віддаватиме стару копію з кешу. Після зміни версії застосунок
оновиться сам при наступному відкритті.

## Дрібні зміни в index.html

- Шрифти тепер тягнуться з Google Fonts (раніше було посилання на локальну папку,
  якої не було, тому шрифти не вантажились). Після першого запуску вони кешуються.
- Додано мета-теги PWA, панель встановлення, індикатор офлайну і підтримку
  safe-area на телефонах з вирізом.
- Логіка драфту, база бравлерів і переклади — без змін.
